# Organisation and oversight

Use the Organisation tab in the local demo administrator account to create faculties, departments and courses, associate a course with one or multiple departments for an academic year, and allocate existing approved tutor accounts. A lecturer can have multiple departmental responsibilities and IV courses. Each course/year has at most one IV coordinator; a course can be unallocated during configuration. Assignment-level conflict checks and release gating will follow separately.

The Feedback oversight tab is deliberately read-only. Departmental lecturer, programme lead and curriculum team lead responsibilities grant read access to learners and feedback in that department's mapped courses for the same academic year. IV coordinators receive read access to their allocated courses. Quality (existing verified admin role) receives cross-course oversight. Multiple scope paths are deduplicated. Feedback creation, status changes, conversations and evidence remain governed by the existing participant/teaching cohort checks. No private quality comments, role self-assignment or access to raw evidence files are added.

No automatic department access is inferred from existing cohort enrolments, and no production learner data is imported. Staff accounts must already be provisioned through the approved identity process. In Entra mode, catalogue management requires an admin account explicitly listed in FEEDBACK_LOOP_ORGANISATION_ADMIN_USERS (comma-separated local IDs); the verified Quality app role alone cannot change allocations. In demo mode the synthetic admin-1 account may manage configuration. New tables are additive; the pilot still needs reviewed production migrations and governance before live use. Organisation changes are logged with previous and new values; annual allocation records remain separate. An administrator can correct the selected year's configuration, which immediately changes access for that year. Teaching allocation is still represented by cohort enrolments; a module-specific allocation UI is not included here.

Run backend tests and browser journeys before merging. No live Microsoft Graph calls are made.
